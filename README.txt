# 妹抖酱 v0.1

一只住在你桌面上的 AI 伙伴。**完全本地运行**，有自己的形象、记忆和脾气。

| | |
|:---|:---|
| **能聊天** | 接 DeepSeek 云端或本地 Ollama，支持思考链、流式回复、工具调用 |
| **有形象** | Live2D 立绘随对话状态换表情；也能听懂「笑一个」「跳个舞」 |
| **记得你** | 跨会话记住你的偏好与习惯，越用越熟 |
| **能干活** | 联网搜索、查资料库、读写文件，直接说就行 |
| **不串味** | 多工作空间隔离 —— 工作 / 学习 / 娱乐各自独立的人设与记忆 |
| **能换肤** | 亮色 / 深色 / 初音三套主题，还能用色轮自己调 |

---

## 安装

### 需要什么

| 依赖 | 说明 |
|:---|:---|
| Python ≥ 3.11 | 用到标准库 `tomllib` |
| [Ollama](https://ollama.com) | 本地模型推理。**向量检索必需**，对话模型可选（也可以用云端） |
| 可选 | Tesseract-OCR（图片文字识别）、HTTP 代理（联网搜索）、Docker（自建搜索服务） |

### 步骤

```powershell
# 1. Python 依赖
python -m pip install -r requirements.txt

# 2. 向量模型（历史检索 / 资料库必需）
ollama pull bge-m3

# 3. 如果要用本地对话模型
ollama pull qwen3.5:9b
```

---

## 运行

```powershell
python main.py
```

也可以双击 **`启动妹抖酱.bat`**。

启动后会直接打开一个无边框桌面窗口（不用浏览器）：左侧导航、中间聊天、右侧立绘舞台。

> 首次启动需要 10~30 秒：加载插件 → 恢复上次的工作空间 → 预热向量模型 → 拉取立绘。
> 窗口会先显示出来，耐心等一下即可。

## 配置

### 填 API Key（用云端模型时）

**不要把密钥明文写进配置文件。** 推荐这样：

1. 在程序里打开「**设置 → 模型**」，填入密钥。
   程序会自动把真值写进 `config/apikey.local`（该文件已被 `.gitignore` 忽略，不会进版本库），
   而 `config/model.toml` 里只留一个 `${MEIDO_站点名_KEY}` 引用。
2. 也可以手工编辑 `config/apikey.local`，每行一个：`KEY = "VALUE"`。
   从模板开始：`cp config/apikey.local.example config/apikey.local`
3. 也可以用系统环境变量（优先级更高，同名变量不会被覆盖）。

> 妹抖酱**不会自动读取 `.env` 文件**；`.env.example` 只是列出可用变量供参考。

### 选模型

「**设置 → 模型**」里选服务商与模型：

| 服务商 | 说明 |
|:---|:---|
| `deepseek` | 云端，需要 API Key |
| `ollama` | 本地，需先 `ollama pull` |
| `lmstudio` / `custom` | 其它 OpenAI 兼容服务 |

### 改人设

「**设置 → 人设**」里改名字、问候语和全局人设。也可以直接编辑 `config/persona.toml`
（支持多行文本，含英文双引号也没问题）。

### 立绘的动作 / 表情

「**设置 → Live2D**」里两处都能**从列表里选**，不用去翻模型目录抄文件名：

- **对话状态 → 动作 / 表情**：两列下拉框，候选就是当前模型里真实存在的动作和表情。
  增删了模型文件后点「重新扫描模型目录」刷新。清单里没有的名字也仍可手输。
- **点击轮换表情**：可滚动的勾选列表。**勾选顺序 = 点击立绘时的轮换顺序**，
  下方会按顺序把已选列出来。

### 让它控制自己的表情

聊天时直接说就行：

> 「笑一个」「害羞一点」「生气」「别笑了」「跳个舞」

她会从当前模型的表情 / 动作里挑最接近的切过去，**保持到这条回复说完**，然后自动恢复。
动作是一次性的，播完自己停。

### 改颜色主题

「**设置 → 外观 → 颜色主题**」内置三套：

| 主题 | 说明 |
|:---|:---|
| 亮色 | 默认 |
| 深色 | 夜间用 |
| 初音 | 青绿 `#39C5BB` 系 |

点「**自定义…**」打开色轮面板：左边 18 个语义色，右边 HSV 色轮 + 明度滑杆 + 色值输入，
下方用真实控件实时预览，并做 7 项 WCAG 对比度检查（不达标会红字提示，但**不阻止**你保存）。

## 常用命令

在聊天框里输入（以 `/` 开头）：

| 命令 | 作用 |
|:---|:---|
| `/model [名称]` | 查看当前模型与服务商状态 / 切换模型 |
| `/think on\|off` | 开关思考链 |
| `/effort [档位]` | 查看 / 调整推理强度 |
| `/memory` | 查看概览卡（`/memory clear` 清空） |
| `/history` | 会话概况；`/history new` 开新会话；`/history export markdown\|json\|txt` 导出 |
| `/pin [规则]` | 查看固定规则 / 固定一条规则（注入人设，重启后仍生效） |
| `/remember <内容>` | 直接把内容写进长期记忆 |
| `/plugin_reload` | 重新加载全部插件 |
| `/self_scan` `/self_status` | 查看 / 清空「自我认知」记忆库 |
| `/search` `/deep` `/crawl` `/search_config` | 联网搜索 / 深度抓取 / 递归爬取 |
| `/kb_add` `/kb_search` `/kb_hybrid` `/kb_related` `/kb_status` `/kb_rebuild` `/kb_mcp` | 资料库增删查与混合检索 |
| `/ls` `/view` `/info` | 浏览项目文件 |

### 让它帮你改文件

直接说「把 xx.py 的某段改成…」即可，她会用 `write_file`（整体写入）、
`edit_file`（精确片段替换）、`delete_file`（默认关闭）动手。

有几层保护：

- **白名单**：默认只能碰 `~/Desktop` 和项目目录，且会校验真实路径，防 `../` 穿越
- **自动备份**：覆盖或删除前先备份到 `.meido_backups/`，滚动保留若干份
- **改自身代码会自检**：改到核心代码时，写完自动跑一遍测试，**失败即回滚**
- **可选二次确认**：开启后先给你看 diff，你确认了才落盘
- **审计**：每次写入都记在 `data/audit/file_edits.jsonl`

## 常见问题

| 现象 | 原因与解法 |
|:---|:---|
| 搜索报「本机代理 127.0.0.1:7897 连不上」 | 联网搜索需要代理。启动 Clash 之类的代理，或把 `plugins/web_search/config.yaml` 的 `proxy` 改成可用地址；也可以自建搜索服务并填 `searxng_url` |
| 启动时提示「未安装 tomli_w」 | 走了内置的降级写法，功能正常，但建议 `python -m pip install tomli_w` |
| 首次启动很慢 | 要加载对话模型并预热 `bge-m3`，属正常现象 |
| 窗口没立即出现内容 | 窗口会先显示，插件 / 工作空间 / 向量模型就绪需要 10~30 秒 |
| 想看实时日志 | 「**设置 → 日志 → 打开调试窗口**」点一下**立即**开一个控制台，不用重启。想让每次启动都自动开，把 `config/bot.toml` 的 `[logging] show_console` 改成 `true`。不看窗口也行：日志在 `data/logs/meido.log`，托盘右键 →「查看日志」可直接打开 |
| Live2D 不显示，日志里有 `[live2d] 页面加载失败` | 某些受限环境（虚拟机 / 开发容器 / 远程桌面）里 Chromium 沙箱起不来。双击 **`测试WebEngine.bat`** 跑自检：它会分别用「默认」和「`--no-sandbox`」加载一次并实测模型。若只有后者成功，就把环境变量 `QTWEBENGINE_CHROMIUM_FLAGS` 设成 `--no-sandbox` 再启动（**会降低浏览器进程隔离，确认需要时再用**）。模型加载不出来时会自动回退到静态立绘，不会崩 |
| 配置文件写坏了（漏引号、`=` 写成 `:` 之类） | 程序**不会崩**。坏掉的文件会回落到默认值启动，并弹出提示告诉你**哪个文件、什么原因、怎么改**。原文件一个字节都不会动，首次发现时会另存一份 `config/<文件名>.bak-<时间戳>`。把语法改好重启即可 |
| 某个工作空间打不开 | 它的 `workspace.toml` 可能被写坏了：程序会自动备份成 `.bak-<时间戳>` 并用默认值重建，细节见日志 |
| 主题改了但重启后又变回亮色 | 外观是「停手 800ms 后」才落盘的（特效滑杆连续触发，逐次写盘会把磁盘敲烂）。确认 `config/appearance.toml` 可写 |
| 自定义的配色看不太清 | 色轮面板底部会列出不达标的组合（WCAG AA 4.5:1）。**只提示不阻止** —— 你选了完全自由，但得知道代价 |
| 消息旁边没有时间戳 | 时间戳从本版本起才开始记录。**本版本之前的旧会话没有时间戳，回放时就不显示**（不拿别的时刻冒充） |
| 点 ✕ 窗口消失但进程还在 | 这是「最小化到托盘」的预期行为。点托盘图标恢复，托盘右键可退出 |
| 托盘图标不显示 | 系统托盘不可用时程序会自动跳过（不报错），关闭窗口即退出 |
| 图片识别不可用 | `pytesseract` 还需要另装 Tesseract-OCR 可执行文件并加进 PATH |
| 搜索 / 资料库提示「集合为空，已按当前 embedding 维度重建」 | 换过嵌入模型导致维度变了，程序会自动切换并重建（旧数据保留不删），属正常自愈 |

## 反馈

遇到问题、想要新功能，都欢迎开 issue：

**👉 https://github.com/bbmio/meidochan/issues**

提问题前顺手带上这几样，能快很多：

- **版本**：程序里「设置 → 关于」或标题栏能看到
- **日志**：`data/logs/meido.log` 的最后一段（托盘右键 →「查看日志」可直接打开）
- **怎么复现**：你说了什么、期望什么、实际发生了什么
- **环境**：操作系统、Python 版本、用的是云端模型还是本地 Ollama
