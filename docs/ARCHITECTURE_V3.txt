## 4. 关键接口契约（执行方必须按此实现）

> 这些接口是「预留扩展」的落地方式：**将来加 MCP / SQL / 动效 / Live2D，只新增实现类，不改调用方**。

### 4.1 媒体层（M1 定义，仅实现 IMAGE）

```python
# ui_qt/media/base.py
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from enum import Enum
from pathlib import Path
from typing import Callable

class MediaKind(str, Enum):
    IMAGE      = "image"     # ✅ M1 实现（png/jpg/webp 静态）
    ANIM_IMAGE = "anim"      # ⏳ 预留（gif / 动图 webp）
    LOTTIE     = "lottie"    # ⏳ 预留
    LIVE2D     = "live2d"    # ⏳ 预留
    PROCEDURAL = "proc"      # ⏳ 预留（粒子 / 代码特效）

class AgentState(str, Enum):
    IDLE = "idle"; THINKING = "thinking"; WORKING = "working"
    RESPONDING = "responding"; ERROR = "error"; SURPRISE = "surprise"

@dataclass
class LayerStyle:
    """虚化 / 透明 / 布局统一描述，与媒体类型无关。"""
    visible: bool = True
    opacity: float = 1.0          # 0..1，层透明
    blur_radius: float = 0.0      # >=0，层虚化（景深）
    scale: float = 1.0
    anchor: str = "bottom-center"
    offset: tuple[int, int] = (0, 0)
    z: int = 0

@dataclass
class AssetSpec:
    id: str
    kind: MediaKind
    path: Path
    style: LayerStyle = field(default_factory=LayerStyle)
    params: dict = field(default_factory=dict)   # 各类型私有参数

class MediaSource(ABC):
    kind: MediaKind
    @abstractmethod
    def attach(self, host) -> None: ...
    @abstractmethod
    def detach(self) -> None: ...
    @abstractmethod
    def apply_style(self, style: LayerStyle) -> None: ...
    @abstractmethod
    def set_state(self, state: AgentState) -> None: ...   # 静态图可忽略
    def start(self) -> None: ...
    def stop(self) -> None: ...

class MediaRegistry:
    """kind -> factory。新增动效类型 = register 一个新的工厂。"""
    def register(self, kind: MediaKind, factory: Callable[[AssetSpec], MediaSource]) -> None: ...
    def create(self, spec: AssetSpec) -> MediaSource: ...
```

**舞台（三层合成）**：

```python
# ui_qt/stage_view.py
class StageView(QWidget):
    """backdrop(背景) / stand(立绘) / overlay(特效) 三层，统一管理 LayerStyle。"""
    def set_layer(self, slot: str, source: "MediaSource | None") -> None: ...
    def set_style(self, slot: str, style: LayerStyle) -> None: ...
    def on_agent_state(self, state: AgentState) -> None:
        for src in self._layers.values():
            if src:
                src.set_state(state)
```

**立绘插件（升级现有 `plugins/static_stand`）**：

```python
class StandPlugin(BasePlugin):          # manifest type = "stand"
    def get_sources(self) -> list[AssetSpec]: ...
# M1：StaticStandPlugin -> [AssetSpec(kind=IMAGE, path="stand.png")]
# 将来：LottieStandPlugin -> [AssetSpec(kind=LOTTIE, ...)]，UI 与引擎零改动
```

**约束**：
- M1 **只实现** `MediaKind.IMAGE`；其余 kind 在 `MediaRegistry` 中**不注册**（或注册为抛 `NotImplementedError` 的占位）。
- 虚化/透明**必须**通过 `LayerStyle` 走 `apply_style()`，**禁止**在具体 Source 里写死效果参数。

### 4.2 路径层（M2 前置，全项目替换相对路径）

```python
# core/paths.py
import sys
from pathlib import Path

IS_FROZEN = getattr(sys, "frozen", False)

# 用户数据 / 配置 / 插件 / 素材：始终在 exe（或项目根）旁边 → 可迁移、可编辑
APP_DIR: Path = (Path(sys.executable).parent if IS_FROZEN
                 else Path(__file__).resolve().parent.parent)

# 只读资源（打包进 exe 的静态资源）
RESOURCE_DIR: Path = Path(getattr(sys, "_MEIPASS", APP_DIR))

def app_path(*parts: str) -> Path:      return APP_DIR.joinpath(*parts)
def resource_path(*parts: str) -> Path: return RESOURCE_DIR.joinpath(*parts)
```

**规则**：
- `config/`、`workspaces/`、`plugins/`、`assets/`、`data/` → **一律走 `app_path()`**。
- 打包内的只读资源 → `resource_path()`。
- 全项目 `Path("config")`、`Path("workspaces")` 这类相对路径**必须全部替换**（`ui/chat_page.py` 里已有 `Path("workspaces/.initialized")` 等，属高危）。

### 4.3 工具层（M4 统一，MCP 前置）

现状问题：工具机制有**三套平行实现**——`core/brain.py` 的 `BUILTIN_TOOLS`、插件 `manifest.json#tools[]`（声明）、插件 `register_commands()`（执行），执行侧靠 `plugins/manager.py::execute_tool` 里一串 `if cmd == "/xxx"` 硬拼字符串。**必须先统一**，否则 MCP/SQL 会污染 `brain.py`。

```python
# core/tools/base.py
class RiskLevel(str, Enum):
    READ = "read"; WRITE = "write"; DESTRUCTIVE = "destructive"

@dataclass
class Tool:
    name: str                       # 全局唯一，见命名空间规则
    description: str
    parameters: dict                # JSON Schema
    handler: Callable[[dict], str]
    source: str                     # "builtin" | "plugin:<name>" | "mcp:<server>" | "sql"
    risk: RiskLevel = RiskLevel.READ
    require_approval: bool = False  # ★复活死字段

class ToolProvider(ABC):
    def list_tools(self) -> list[Tool]: ...
    def call(self, name: str, arguments: dict) -> str: ...
    def start(self) -> None: ...
    def stop(self) -> None: ...
    def health(self) -> dict: ...

class ToolRegistry:
    def register_provider(self, provider: ToolProvider) -> None: ...
    def openai_tools(self) -> list[dict]: ...       # 给 brain 的 tools 参数
    def execute(self, name: str, arguments: dict) -> str: ...  # 统一路由
```

**命名空间规则**：内置 `model`；插件 `kb_search`；MCP `mcp__<server>__<tool>`；数据 `sql__query`。
**风险与审批**：`risk != READ` 或 `require_approval=True` 时，`execute()` 前必须走 `MessageBus.TOOL_BEFORE_EXECUTE`，由 UI 弹确认；拒绝则返回可读说明，不抛异常。

### 4.4 存储层（M4 定义协议，M6 接 SQL）

现状 `workspace/storage.py` 已是手写 Repository（TOML 后端），把它**抽成协议**并补全：

```python
# core/storage/repository.py
class WorkspaceRepository(Protocol):
    def save(self, obj) -> None: ...
    def load(self, key: str): ...
    def list_all(self) -> list: ...
    def delete(self, key: str) -> bool: ...
# 同理：ConversationRepository / MemoryRepository / MemberRepository / AuditRepository
```

**规则**：业务代码**只依赖协议**，不得直接 `open()` 数据文件；后端由 `core/storage/factory.py` 按配置选择 `JsonRepository` / `SqlRepository`。

### 4.5 事件总线（M4 接线；现为**死代码**）

`core/message_bus.py` 已定义 `EventType` 但**全项目从未实例化**。M4 必须接线：

| 事件 | 发布方 | 订阅方 | 用途 |
|------|--------|--------|------|
| `TOOL_BEFORE_EXECUTE` | ToolRegistry | UI / 审批器 | 风险拦截、弹窗审批 |
| `TOOL_AFTER_EXECUTE` | ToolRegistry | AuditRepository | 审计落库 |
| `CONFIG_CHANGED` | 设置面板 | Engine | 运行时热更新 |
| `MESSAGE_RECEIVED` / `MESSAGE_SEND` | Engine | UI | 界面更新 |
| `AGENT_THINKING/WORKING/RESPONDING/ERROR/IDLE` | Brain/Engine | StageView | ★驱动立绘动效（预留） |

`MessageBus` 由 `Engine` 持有并注入各组件（单一实例）。

### 4.6 MCP 接入（M5）

**定位**：妹抖酱作为 **MCP Host/Client**（连外部 Server）；现有 `plugins/knowledge_base/mcp_server.py`（FastMCP 服务端）**保留**，两者不冲突。

- 传输：`stdio`（主力）、`Streamable HTTP` / `SSE`（远程）。
- SDK：官方 `mcp` Python SDK。⚠️ **它是 asyncio，而引擎是同步线程模型** → 必须封装「后台事件循环线程 + `asyncio.run_coroutine_threadsafe`」桥，桥接层**单独成模块并加测试**（这是最容易出 bug 的地方）。
- 配置（外置，用户可增删）：`config/mcp.toml`

```toml
[[servers]]
name      = "filesystem"
transport = "stdio"          # stdio | http | sse
command   = "npx"
args      = ["-y", "@modelcontextprotocol/server-filesystem", "./data"]
enabled   = true

[servers.tools.write_file]   # 按工具覆盖风险策略
risk             = "write"
require_approval = true
```

- 生命周期：`McpManager` 负责 拉起子进程 → initialize 握手 → `list_tools` → 健康检查 → 崩溃重启 → **退出时清进程树**（Windows）。
- 注册：发现的工具 → `McpProvider` → 注入 `ToolRegistry`，命名 `mcp__<server>__<tool>`。
- 安全：默认白名单启用；写/删类默认需审批；限制 server 工作目录；超时 + 输出截断。
- **打包影响**：MCP server 多是 node/python 进程（`npx`/`uvx`），**exe 打不进去**。首启必须检测 `node`/`npx`/`uv`/`uvx` 是否存在，缺失给人话指引；自家 server 优先用**内置 Python 实现**（用打包好的解释器起）。

### 4.7 SQL 接入（M6）

- 引擎：**默认 SQLite**（单文件、零运维、最好迁移）；接口留 Postgres/MySQL 口子。
- 访问层：SQLAlchemy 2.x + Alembic（若体积敏感可退化为 `sqlite3` + 自管 `schema_version`）。
- 进 SQL 的数据：会话消息、会话摘要、长期记忆、概览卡、群成员、**工具审计日志**、索引元数据。
- 留 TOML 的数据：配置、人设、角色、pins（静态、人要读改）。
- 表草案：

```
conversations(id, workspace_id, session_id, role, content, created_at, meta_json)
sessions(id, workspace_id, title, summary, created_at, updated_at)
memories(id, workspace_id, kind, key, value, updated_at)
members(platform, user_id, display_name, aliases_json, last_seen)   -- 预留：纯桌面无此需求，供未来适配器
tool_audit(id, workspace_id, tool, args_json, result_ref, risk, approved, created_at)
vectors(id, workspace_id, kind, ref_id, embedding_blob, meta_json)   -- 若弃用 Chroma
schema_version(version, applied_at)
```

- 并发：SQLite 开 **WAL**；写操作单写者；多线程写入（引擎后台线程 / UI 线程）必须串行化。
- 迁移：启动检测 `schema_version` → 自动迁移；JSON 全量导入；**保留双写开关灰度**；**迁移前必须备份**。

结果 `accent` 从 `#1A73E8` 换到 `#3E63DD` 之后文档就成了错的。

一个「主题」= 一组同名的 TOKENS 字典（当前 18 个语义色，分 5 组）：

| 分组 | 令牌 |
|------|------|
| 底色与层次 | `bg` `surface` `sidebar-bg` `surface-hover` `code-bg` `border` |
| 文字 | `text` `muted` `disabled` `on-solid` |
| 主色 | `accent` `accent-hover` `accent-soft` `accent-text` |
| 危险色 | `danger` `danger-soft` `danger-text` |
| 滚动条 | `scrollbar` |

- **预设**：`THEMES` = 亮色 / 深色 / 初音；另有 `CUSTOM_THEME_NAME`（自定义）
- **取色**：一律走 `theme.active_tokens()`。`build_qss()` 与自绘控件
  （`speech_bubble`）都从它取，所以 `set_active_theme()` 之后重新
  `build_qss()` 即可全局换肤
- **自绘控件必须手动重绘**：`speech_bubble` 是 `paintEvent` 里 `fillPath` 画的，
  `setStyleSheet` 刷不掉它，得 `update()`（见 `MainWindow.apply_theme`）
- **对比度**：`contrast_report()` 做 7 项 WCAG AA 检查；色轮面板据此提示用户
  （只提示不阻止 —— 用户选了完全自由，但得知道代价）
- **配置**：`config/appearance.toml`。预设名只存名字（预设改进能自动跟上），
  自定义才写 18 个色值
- 圆角 `8/12/14/16`、间距 `4/8/12/16`、字体
  `"Microsoft YaHei UI", "Segoe UI", "Noto Sans SC"` —— Qt **不认** CSS 的
  `system-ui`，实测会被模糊匹配成 Tahoma（为小字号屏幕优化的老字体，高 DPI 下发糙）

### 5.5 虚化 / 透明（用户可调 · 三个层级独立）

| 层级 | 技术 | 可调 |
|------|------|:---:|
| 窗口整体不透明度 | `setWindowOpacity()` | ✅ 滑杆 0.80–1.00 |
| 窗口背景毛玻璃 | Win32 `SetWindowCompositionAttribute`（Acrylic） | ❌ 系统固定半径（开关） |
| 层内虚化（景深） | `QGraphicsBlurEffect(radius)` 作用于**缓存 pixmap** | ✅ 滑杆 0–20 |

**性能红线（必须遵守）**：`QGraphicsBlurEffect` **只作用于已缓存的静态图层**；拖动滑杆时用「降采样→模糊→升采样」，**松手后**才精算；禁止对每帧实时全分辨率模糊（4K 背景会卡）。

**外观预设**：

| 预设 | windowOpacity | 背景虚化 | Acrylic | 立绘景深 |
|------|:---:|:---:|:---:|:---:|
| 清晰 | 1.00 | 0 | 关 | 0 |
| 标准 | 0.98 | 8 | 关 | 0 |
| 沉浸 | 0.92 | 16 | 开 | 2 |

### 5.6 状态联动（预留动效的挂载点）

引擎发布 `AGENT_*` 事件 → `StageView.on_agent_state()` → 分发给所有 `MediaSource.set_state()`。**M1 静态图忽略即可**，但链路必须打通。

## 7. 打包规范

1. **模式**：`--onedir`。理由：启动快、无临时解压、`config/plugins/assets/data` 可外置、杀软误报低。
2. **入口**：`main.py`。**不做** `--onefile`。
3. **控制台**：发布用 `--noconsole`（`console=False`）。**发布版的后台调试窗口改为运行期可选开启**，
   由 `config/bot.toml` 的 `[logging] show_console` 控制（默认 `false`）：
   置 `true` 时 `core/console_window.py` 用 `AllocConsole()` 分配控制台并重定向输出 ——
   同一个 exe，不用换产物。**不采用** `console=True` + 启动后 `ShowWindow(SW_HIDE)`：
   那样系统会先分配控制台再被隐藏，用户必然看到一次黑窗闪烁。
   `build.bat debug`（`console=True`）仍保留，但用途收窄为「PyInstaller bootloader 阶段
   就崩了」的场景 —— 那是 `AllocConsole()` 覆盖不到的阶段。
4. **外置目录**（不打包）：`config/`、`plugins/`、`workspaces/`、`assets/`、`data/`。
5. **必须打包**：引擎全部 Python 依赖、`jieba` 词典、`chromadb` 数据、Qt 图像插件（`qwebp`/`qgif`/`qjpeg`）。
6. **中文 exe 名**：构建用 ASCII 名（`meido.exe`），交付时重命名为 `妹抖酱v0.1.exe`；**exe 所在路径建议纯 ASCII**（中文路径在部分工具链上会出问题）。
7. **交付形态**：`妹抖酱v0.1.zip`（整个 onedir 目录）或 Inno Setup 安装包。
8. **杀软**：onedir + 不压缩壳，降低误报；若仍误报，考虑代码签名。

2. **小步可验证**：每改一个主题即验证；禁止一次性大重构。
3. **不臆造**：不确定标「待确认」；不得谎报"已修复/已测试通过"。
4. **密钥安全**：发现明文 token/API Key，只报「文件:行 + 类型」，**不回显**；改为环境变量 / `.env` + `.gitignore`。**已知问题（M1b 处理）**：本项目 `config/adapters.toml` 的 `[adapters.qq]` 与独立项目 `WhaleGirlQQ/config.toml` 均含**明文** `http_token` / `ws_token`，且已随 `dist/` 产物扩散 → 删除后**必须轮换**（见 §6-M1b）。
5. **异常与日志**：关键路径 `try/except` + 分级 `logging`；**禁止**用 `print` 做正式日志；异常不得静默吞掉。
6. **类型注解 / docstring**：关键函数必加。
7. **配置与代码分离**：配置走 `toml`/`env`，禁止硬编码。
8. **测试**：核心纯逻辑（配置解析、文本清洗、去重、触发器匹配、上下文组装、token 估算、路径解析）必须有 pytest。
9. **依赖**：固定版本（`==`）；新增依赖必须说明理由。
10. **中文**：注释、日志、交互文案用中文（与现状一致）。
